Primary external analysis is a source-compatible event-window transfer diagnostic: one 19-frame window around each annotated blink midpoint; negatives at deterministic non-overlapping 19-frame grid centers with no blink overlap. Exclude windows crossing video boundaries, not failures; report all counts and missing-output rate. A no-output window is an incorrect negative for recall and an abstention separately. Inspect implementation tests before looking at metrics. Do not tune thresholds, matching tolerance, or architecture on results.
