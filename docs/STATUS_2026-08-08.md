`vpres − vdrop = +0.0010 [−0.0032, +0.0069]` — **교락 없는 유일한 비교이고 차이가 없다.**
D 스윕(8/16/32/64)도 전부 구분 불가. 천장 검정 결과 조건 간 오차 겹침이 시드 간과

🔴 **논문 Method 에서 "비대칭 stride 가 핵심"을 근거로 쓸 수 없다.**
`encoder.py` docstring 에서 이미 철회했다.

**vpres 유지** 결정(2026-08-07). 전환 조건은 **Pi 실측 G-E1 실패 시 vdrop** 하나뿐.

## 4. Edge (T5)

**정적 비용** (`export_onnx.json`): encoder 79,424 + head 4,625 = **84,049 params**,
311.4 KB + 23.3 KB = **335 KB**, **12.49 MMAC/frame** (head 0.0459, stride 1 기준, 비중 0.37%)

**Pi 5 실측** (640×480, 4모드 × 300 s, `--intra-threads 2 --no-spin`, governor performance,
스로틀 없음) — **네 모드 전부 G-E1 PASS** (e2e p99 이 예산 33.3 ms 의 30~39%)

| Method | method 소계 p50 | e2e p50 | e2e p99 |
|---|---:|---:|---:|
| EAR | 0.22 | 9.56 | 10.10 |
| **Ours** | **1.78** | 11.27 | 11.85 |
| Image-CNN (max) | 2.88 | 12.26 | 12.87 |
| Image-CNN (head) | 3.03 | 12.51 | 13.10 |

공통 항(네 모드 동일): `read` 1.00~1.02 ms · `detect` **8.32~8.46 ms**

- 표현 단계에서 ours 는 image_cnn 의 **1/2.4** (0.86 vs 2.04 ms) — MMAC 비 2.55 와 일치
- 🔴 **e2e 로는 11% 차이에 그친다.** 얼굴 검출이 68~87% 를 먹는다.
  **에지에서 병목은 인코더가 아니라 검출 프론트엔드다.**

🔴 **미해결**: `results/v2/pi_*_480p.json` 이 저장소에 없다. 위 숫자는 출처 파일 미확인.
또한 480p 클립 매니페스트(10,268 프레임/342 s)와 보고된 프레임 수(31,268/300 s)가 맞지 않는다
— `clips/list7.txt`(7회 concat = 36,281 프레임/1,209 s)로 새 클립을 만드신 것으로 보이나
그 파일이 `clips/` 에 없다. **어느 클립으로 쟀는지 확인 후 `clips_manifest.json` 갱신 필요.**

## 6. 이번 라운드에서 고친 구조적 결함

| # | 결함 | 조치 |
|---|---|---|
| 1 | `MODELS = "models/v2"` 하드코딩 — 모든 런이 같은 자리에 저장 | `--out` 에서 파생. 서로 다른 `--out` 은 **구조적으로 충돌 불가** |
| 2 | `env_fingerprint()` 를 JSON 쓰는 시점에 호출 → 커밋이 실행 코드를 못 지목 | `freeze_env()` 로 **프로세스 시작 시 1회 고정** |

| 4 | "인과적 TCN" 서술이 실측과 다름 | 대칭 패딩이라 창 안에서 미래를 본다(실측). **"causal" 금지**, non-lookahead 로 정정 |
| 5 | `compare_variants` 가 image_cnn 자리에 vpres 비용을 찍음 | `config['front']` 를 보도록 수정 |
