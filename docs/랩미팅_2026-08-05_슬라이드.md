## 슬라이드 1 — 한 장 요약

**"눈 크롭에서 뽑은 16차원 벡터가 EAR 만큼 깜빡임을 잡는가, 그리고 그 벡터는 신원을
얼마나 흘리는가"를 mEBAL2 57명에서 측정했습니다.**

| | 결과 |
|---|---|
| 유용성 | **통과** — EAR 대비 비열등을 넘어 우월 (PR-AUC +0.0151, 95% CI [+0.0106, +0.0203]) |
| 프라이버시 | **누출이 크다** — 57명 재식별 **0.6345** (chance 0.0175, **36배**) |
| 핵심 발견 | 학습된 인코더가 **학습을 전혀 안 한 랜덤 인코더(0.6261)와 같은 수준**으로 샌다 |
| 뜻 | 누출의 원인은 목적함수가 아니라 **눈 크롭 입력 자체**다 → **억제를 인코더 단에 넣어야 한다** |

> **최종 목표는 인코더 단에서 신원 재식별을 불가능하게 만드는 것**입니다.
> 오늘 보고하는 것은 그 목표를 향한 **기준선 계측**이며 최종 결과가 아닙니다.
> 프라이버시의 주 근거인 **복원 장벽은 아직 안 쟀습니다**(슬라이드 8).

## 슬라이드 4 — 유용성: 비열등 판정 통과 (사실은 우월)

**판정 기준을 결과 보기 전에 얼렸습니다** (2026-08-01, 우리 결과 0건인 시점):
주 지표 **PR-AUC**, 마진 **δ = 0.02**, 짝지은 피험자 클러스터 부트스트랩 95% CI 하한 > −δ.

피험자 분리 5-fold × 3시드 = 15런 (`results/v2/train_encoder.json`)

| | PR-AUC |
|---|---|
| **ours** (비대칭 CNN, D=16) | **0.9886 ± 0.0038** |
| ear_head (EAR×19 → **동일 판정 헤드**) | 0.9724 ± 0.0096 |
| ear_rule (규칙 기반 drop_ratio) | 0.8931 ± 0.0136 |
| **차이 (ours − ear_head)** | **+0.0151, 95% CI [+0.0106, +0.0203]** → **superior** |

### 이 숫자를 믿어도 되는 이유 — 베이스라인부터 의심했습니다

이 라운드에서 우리 우위가 **+0.1058 → +0.0323 → +0.0151** 로 **두 번 줄었습니다.**

1. 규칙 기반 EAR 을 **동일 판정 헤드**로 교체 (대조군이 프로토콜 요구보다 약했음)
2. 고정 에폭을 **동일 중단 규칙**으로 교체 (베이스라인만 학습이 덜 끝나 있었음)

점검: ear_rule 이 사전 실측(0.8825)보다 **높고**(0.8931), 15런 모두 수렴,
val 낙관은 ours +0.0021 / ear_head +0.0028 로 거의 같습니다.

## 슬라이드 5 — 프라이버시: 학습해도 누출이 안 줄어듭니다 ★★

57명 균형 표집 11,400장, chance **0.0175** (`results/v2/phase5_reid.json`)

| 표현 | 차원 | 시간블록 MLP |
|---|---:|---:|
| (b) 원본 픽셀 — **천장** | 10,240 | 0.9080 |
| (c) 픽셀 PCA-32 | 32 | 0.8669 |
| **ours (학습된 인코더, 15모델)** | **16** | **0.6345 ± 0.0288** |
| (a) **랜덤 초기화 인코더 (학습 없음)** | 16 | **0.6261** |
| (d') 광학 3차원 — **바닥** | 3 | 0.0825 |
| (e) EAR 스칼라 | 1 | 0.0548 |

### 세 줄 결론

1. **학습을 전혀 안 한 랜덤 인코더가 우리와 같은 수준으로 샙니다** (0.6261 vs 0.6345,
   차이가 모델 간 std 의 1/3). → **누출의 원인은 목적함수가 아니라 눈 크롭 입력입니다.**
2. **차원 축소는 해법이 아닙니다.** 10,240 → 16 으로 640배 줄여도 0.63 입니다.
3. **조명 때문이 아닙니다.** 광학 바닥이 0.0825 이므로 나머지는 구조·질감입니다.

### 다중 관측이면 완전히 식별됩니다

| N (한 사람에게서 모은 벡터 수) | 정확도 |
|---:|---:|
| 1 | 0.9139 |
| 10 | 0.9960 |
| **100** | **1.0000** |

(52명 코호트, chance 0.0192. 무작위 분할·최악 모델 기준의 **상한** 보고이며,
프로브 학습 표본이 9배 커서 N=1 값을 위 표와 직접 비교하지 않습니다)

> 📌 **현 시점에서 "우리 표현은 신원을 담지 않는다"고 쓸 수 없습니다.**
> 이 값은 **억제를 넣기 전 기준선**이고, 최종 목표인 "인코더 단 재식별 불가능"까지
> 파레토 게이트(재식별 < 0.086) 기준 **7.4배** 남았습니다.

## 슬라이드 6 — 방법론: 게이트가 실제로 사고를 잡았습니다

**규칙은 `docs/v2/PROTOCOL.md` 한 곳에만 적고, 코드는 `src/v2/common/` 하나만 씁니다.**
Phase −1 게이트 (`results/v2/gate_minus1.json`).

게이트가 잡아낸 것 중 셋:

| | 잡은 것 |
|---|---|
| **격자 해상도** | 처음 채택했던 logit 분위수 격자는 저-FA 구간의 **23%만** 짚었습니다. 낮은 false-alarm 을 결정하는 음성 분포의 위쪽 꼬리가 **한가운데** 있었기 때문입니다. 유일값 전체 격자로 바꿔 **100%** 활용 |
| **chance 불균형** | 1/58 만 쓰면 성능을 **4.3배 과대평가**합니다(다수 클래스만 찍어도 0.0734). 균등·다수 병기 강제 |
| **학습 결정성 (신규 G-1i)** | 기존 게이트는 합성 MLP 만 돌려 Conv2d 역전파를 안 지나갔습니다. **실제 인코더로 재작성** → 손실·가중치 비트 동일 PASS. 이제 ± 를 인용할 수 있습니다 |

### 선형 프로브만 보면 안 되는 이유 — 두 번 값을 했습니다

| | 선형 | MLP |
|---|---:|---:|
| 광학 교란 (Phase 0) | 0.0767 | **0.2018** (2.6배) |
| ours 재식별 (Phase 5) | 0.4783 | **0.6345** |

ours 는 랜덤 인코더 대비 **선형만 내려가고(0.5017→0.4783) MLP 는 그대로**입니다.
이건 프라이버시 기전이 아니라 **프로브 회피 패턴**이고, 우리는 억제를 하지도 않았으니 우연입니다.

## 예상 질문

**Q. 왜 우월인데 비열등이라고 말하나?**
기여 문장이 "동일 유용성 조건에서 신원 노출량을 정량화한다"라서 유용성 동등은 주장이
아니라 **전제 조건**입니다. 게다가 안경군 우위가 +0.0084 로 작아서 우월을 밀면
그 표가 반론이 됩니다.

**Q. 0.9886 은 너무 높지 않나? 뭔가 새는 것 아닌가?**
세션 시각 교락을 대조군 8 로 검사해 배제했습니다(위). 다만 대조군 2·3·4 가
아직이라 "표현의 기여"와 "학습된 판정 규칙의 기여"는 분리 전입니다.

**Q. 재식별 0.63 이면 프라이버시가 없는 것 아닌가?**
맞습니다. 오늘 보고하는 것은 **억제를 넣기 전 기준선**입니다.
그리고 랜덤 인코더가 이미 0.63 이라는 점이, 억제를 어디에 걸어야 하는지를 말해줍니다
— 목적함수가 아니라 **입력 단계**입니다.

**Q. 58명은 적지 않나?**
mEBAL2 전체는 180명이고 우리가 받은 배포본이 58명입니다. 논문에 그대로 씁니다.
피험자 분리 5-fold 에 배치 이중 층화를 걸었고, 신뢰구간은 **피험자 클러스터**
부트스트랩이라 이벤트를 독립 표본처럼 세지 않습니다.
