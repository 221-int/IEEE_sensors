### p3 — 시스템 파이프라인

현재: `크롭 → 인코터(오토인코더) → 128차원 벡터 → MLP 판정 → 깜빡임`.

**[정정] 파이프라인 전면 교체**

```
눈 크롭 (64×160, margin 2.2, 프레임 표준화)
  → vpres CNN 인코더 (비대칭 stride) → 프레임당 16차원 벡터
  → 19프레임 링버퍼 (+ 결측 마스크)
  → 인과적 TCN (dilation 1·2·4) + MLP → blink 확률
```

**[추가] 설계 근거 — 왜 비대칭 stride 인가 (질문 대비 핵심)**

| 항목 | 값 |
|---|---|
| 눈꺼풀 상하 간격 (크롭 기준) | **8.73 px** (세로 64 px 중) |
| 대칭 stride-2 × 4회 적용 시 | 8.73 / 16 = **0.55 px** → 깜빡임 신호가 특징맵에서 소멸함 |
| 채택안 vpres (세로 총 stride 2) | 병목에서 **4.37 px** 잔존 |
| 연산량 | 인코더 **12.44 MMAC** / 시간 헤드 **0.046 MMAC**(이벤트당) |

- 가로 160 px 은 두 눈을 나란히 담기 위한 폭이지 해상도가 필요한 축이 아님. 따라서 **가로만 32배 축소, 세로는 2배만 축소**함.
- 프레임마다 19장을 재인코딩하면 비용이 19배가 되어 Pi 예산 초과임. **프레임당 인코딩 1회 + 벡터 링버퍼**로 해결함.
- 얼굴 해소 실패 프레임은 0으로 채우지 않고 **마스크로 표시해 pooling 에서 제외**함. "변화 없음"과 "모름"을 구분하기 위함임.

출처: `src/v2/model/encoder.py`

**[정정] 하단 불릿 수정**
- 기존: "라즈베리파이5 + ONNX 경량화" → **"라즈베리파이5 + ONNX 경량화 (v2 지연은 Phase 6 에서 재측정 예정, 미착수)"**
- 유지: "판정 경로에 랜드마크/EAR 미사용" — 사실임. 다만 **EAR 은 베이스라인 계산에만 사용**한다는 점을 병기할 것.

### p6 — 결과 ① 유용성

현재: 막대 3개 + 차이 카드. 수치는 정확함.

**[추가] 표준편차 병기**

| | PR-AUC |
|---|---|
| **ours** (vpres D=16) | **0.9886 ± 0.0038** |
| ear_head (EAR×19 → 동일 판정 헤드) | 0.9724 ± 0.0096 |
| ear_rule (규칙 기반 drop_ratio) | 0.8931 ± 0.0136 |

**[추가] 이 숫자를 믿어도 되는 이유 — 우위가 두 번 줄어든 이력**

이번 라운드에서 우리 우위는 **+0.1058 → +0.0323 → +0.0151** 로 두 번 축소됨.

1. 규칙 기반 EAR 을 **동일 판정 헤드**로 교체함 (기존 대조군이 프로토콜 요구보다 약했음).
2. 고정 에폭을 **동일 중단 규칙**으로 교체함 (베이스라인만 학습이 덜 끝난 상태였음).

베이스라인 약화 점검 결과:
- ear_rule 이 사전 실측(0.8825)보다 **오히려 높음**(0.8931).
- 15런 전부 `converged_earhead=True`, max_epochs 80 도달 0건.
- val 낙관은 ours +0.0021 / ear_head +0.0028 로 거의 동일함.
- fold 내 시드 std 최대 **0.0050** < 조건 차이 0.0162 → "미측정" 조건에 해당하지 않음.

**[추가] 척도 없는 지표 병기 — 이득이 소수에만 몰린 것이 아님**

절대 PR-AUC 이득만 보면 ours 가 0.98 대 천장이라 이득 상한이 `1 − baseline` 으로 눌림. 오류비 `(1−ours)/(1−ear_head)` 로 보면 다름.

| 구간 | 오류비 중앙 | <1 인 인원 |
|---|---:|---:|
| 전체 57명 | 0.385 | 52/57 |
| ear_head 하위 25% (15명) | 0.411 | 14/15 |
| ear_head **상위** 75% (42명) | **0.355** | 38/42 |

→ 오류 감소가 **전 구간에 존재**함. 다만 절대 PR-AUC 로는 강한-EAR 구간에서 크기가 의미 있다고 말할 수 없음.

**[주의] 초안 하단 해석 문구 유지 권장**
- "우월"이라는 단어를 전면에 세우지 말 것. 기여 문장이 *"동일 유용성 조건에서 신원 노출량을 정량화함"* 이므로 유용성 동등은 주장이 아니라 **전제 조건**임. 안경군 이득이 작아 우월을 밀면 그 표가 반론이 됨.

### p7 — 결과 ② 신원 누출

현재: 막대 6개 + 핵심 해석 + 집계 공격. 이번 덱에서 가장 완성도가 높은 페이지임.

**[추가] 세 줄 결론을 명시적으로 배치**

1. **학습을 전혀 하지 않은 랜덤 인코더가 우리와 같은 수준으로 누출함** (0.6261 vs 0.6345, 차이 +0.008 = 모델 간 std 0.0288 의 1/3). → 누출 원인은 목적함수가 아니라 **눈 크롭 입력 자체**임.
2. **차원 축소는 해법이 아님.** 10,240 → 16 으로 **640배** 줄여도 0.63 임.
3. **조명 때문이 아님.** 광학 3차원 바닥이 0.0825 이므로 나머지는 **구조·질감**임.

**[추가] 위치 감각을 주는 세 배수**
- chance 의 **36배**, 픽셀 천장의 **70%**, 광학 바닥의 **7.7배**.

**[추가] 선형 프로브만 보면 안 되는 이유 (p8 로 옮겨도 무방함)**

| 비교 | 선형 | MLP |
|---|---:|---:|
| 광학 교란 (Phase 0) | 0.0767 | **0.2018** (2.6배) |
| ours 재식별 (Phase 5) | 0.4783 | **0.6345** |

- ours 는 랜덤 인코더 대비 **선형만 하락(0.5017 → 0.4783)하고 MLP 는 그대로**임.
- 이는 프라이버시 기전이 아니라 **프로브 회피 패턴**이며, 억제를 수행하지도 않았으므로 우연임.

**[추가] 집계 공격 단서 조항 (질문 대비 필수)**
- 코호트가 다름: 피험자당 2,000장 이상인 **52명**, chance 0.0192.
- 프로브 학습 표본이 104,000 으로 위 표(11,400)보다 9배 많아 **N=1 값을 위 표와 직접 비교하면 안 됨**. 곡선 내부(N=1 vs 10 vs 100)만 비교 가능함.
- 집계는 시간 구조를 깨므로 **무작위 분할**이며, 15개 모델 중 **누출이 가장 큰 것**을 선택한 **상한 보고**임.

**[추가] 결론 문장 (박스 권장)**
> 논문에 "우리 표현은 신원을 담지 않는다"고 쓸 수 없음.
> 이번 라운드의 기여는 **동일 유용성 조건에서 신원 노출량을 정량화한 것**임.

### p8 — 방법론 검증 게이트

현재: 카드 4개(격자·분할·선택·결정성) + PASS 배너. 항목은 맞으나 **게이트가 실제로 무엇을 잡았는지**가 없어 설득력이 약함.

**[추가] 게이트가 잡아낸 실제 사고 3건**

| 게이트 | 잡아낸 것 |
|---|---|
| **격자 해상도** | 처음 채택했던 logit 분위수 격자가 저-FA 구간의 **23%만** 짚음. 낮은 false-alarm 을 결정하는 **음성 분포의 위쪽 꼬리가 한가운데** 있었기 때문임. 유일값 전체 격자(40,001점)로 교체해 **100%** 활용 |
| **chance 불균형** | 1/58 만 쓰면 성능을 **4.3배 과대평가**함 (다수 클래스만 찍어도 0.0734). 균등·다수 병기를 강제함 |
| **학습 결정성 (신규 G-1i)** | 기존 게이트는 합성 MLP 만 돌려 **Conv2d 역전파를 지나가지 않음**. 실제 인코더로 재작성 → 손실·가중치 비트 동일 PASS. 이제 ± 를 인용 가능함 |

**[추가] 격자 비교 표 (숫자로 보여줄 경우)**

| 격자 | 격자점 | 실제로 짚은 FA 값 | 활용률 |
|---|---:|---:|---:|
| **exhaustive (v2 채택)** | 40,001 | 100 | **100.0%** |
| 분위수 logit 257, 클래스별 | 773 | 60 | 60.0% |
| 분위수 logit 257, 섞인 분포 | 259 | 23 | 23.0% |
| 분위수 선형 97 | 99 | 10 | 10.0% |

**[추가] 교락 검사 통과 — "세션 시각으로 갈랐을 뿐 아니냐"에 대한 대비**

| 검사 | 결과 |
|---|---|
| t_rel 단독 MLP | **0.5282** (유병률 0.4978) |
| EAR + t_rel | 0.8931 → 0.8899 (**−0.0032**, 개선 없음) |
| Spearman(\|Δ\|, 우리 이득) | **+0.088**, CI [−0.176, +0.361] — 0 포함 |
| \|Δ\| 상위/하위 절반 이득 | +0.0087 / +0.0135 (오히려 반대 방향) |

- **[주의]** 이 검사는 EAR 위에서만 측정함. "우리 표현이 시간을 쓰는가"의 직접 검사는 아님.

**[추가] 초안 하단 문구 유지 + 사고 기록 언급 권장**
- 2026-08-03 에 게이트가 검사 대상을 **두 번 덮어씀** (얼린 fold 1회, CUDA 실행 기록 1회). 양쪽 모두 재발 방지 조치 완료함.
- 교훈: **게이트가 검사 대상을 쓰면 그것은 게이트가 아님.**

## 3. 예상 질문과 답변

**Q. 우월인데 왜 비열등이라고 말하는가.**
기여 문장이 "동일 유용성 조건에서 신원 노출량을 정량화함"이므로 유용성 동등은 주장이 아니라 **전제 조건**임. 또한 안경군 이득이 +0.0084 로 작아 우월을 밀면 그 표가 반론이 됨.

**Q. PR-AUC 0.9886 은 너무 높지 않은가. 무언가 새는 것 아닌가.**
세션 시각 교락은 대조군 8 로 검사해 배제함(t_rel MLP 0.5282, EAR+t_rel 개선 없음). 다만 대조군 2·3·4 가 미측정이라 "표현의 기여"와 "학습된 판정 규칙의 기여"는 아직 분리 전임.

**Q. 재식별 0.63 이면 프라이버시가 없는 것 아닌가.**
사실임. 오늘 보고하는 것은 **억제를 넣기 전 기준선**임. 그리고 랜덤 인코더가 이미 0.6261 이라는 점이 억제를 어디에 걸어야 하는지를 지시함 — 목적함수가 아니라 **입력 단계**임.

**Q. 57명은 적지 않은가.**
mEBAL2 전체는 180명이며 배포본이 58명임. 논문에 그대로 표기함. 피험자 분리 5-fold 에 배치 이중 층화를 적용했고, 신뢰구간은 **피험자 클러스터** 부트스트랩이므로 이벤트를 독립 표본처럼 계수하지 않음.

**Q. 128차원에서 16차원으로 줄인 이유는.**
차원 축소는 프라이버시 목적이 아님(640배 축소에도 재식별 0.63). D=16 은 **연산 예산과 유용성**을 기준으로 고정한 값이며, 세로 해상도 보존(비대칭 stride)이 실제 성능 요인임.

**Q. 오토인코더를 왜 버렸는가.**
재구성 목적함수는 깜빡임과 무관한 정보(신원·조명·질감)를 함께 보존함. v2 는 깜빡임 라벨로 **직접 지도학습**하며, 디코더는 검증 도구로만 유지함.
